Edge App Gateway 配置生成器

一个文件管理整个 Worker 的多应用变量、Secrets 和 Custom Domains。页面完全离线运行，不发送网络请求，也不使用浏览器存储。

1. Gateway 与变量文件

应用入口统一为 alias.基础域名。

只有至少一个应用启用 Edge 登录时需要；留空可自动生成。

导入或备份完整变量文件

变量文件包含所有项目的 Origin Secret，属于敏感文件。仅保存在密码保险库、加密磁盘或受控 WebDAV 目录，不要提交 Git。

2. 应用列表

每个应用只需填写 Alias 和 Vercel Production URL；入口域名、Binding 和安全默认项自动生成。

3. 部署与 WAF

推荐直接导出变量文件，然后运行 npm run deploy:config -- 文件路径。脚本会通过 Wrangler 一次配置代码、普通变量、Secrets 和全部 Custom Domains，不需要 Cloudflare Dashboard。
